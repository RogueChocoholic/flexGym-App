## 📘 Project Description

**flexGym** is a complete standalone Gym Management System developed with **Java Swing**.  
It is designed to help gym owners efficiently manage memberships, sell gym-related products, schedule training sessions, and handle daily operations.

The system supports barcode-based membership and product management, and also allows printing invoices and reports for sales, memberships, and trainer schedules.

---

## ✨ Features

- 📝 **Membership Management**  
  Register new members and manage their details easily.

- 🛒 **Point of Sale (POS) System**  
  Sell gym equipment, beverages, and supplements.

- 📅 **Training Session Scheduling**  
  Book and organize personal training sessions.

- 🧑‍🏫 **Trainer Registration**  
  Add and manage gym trainers and their assigned sessions.

- 🖨️ **Invoice and Report Generation**  
  Generate printable invoices and reports for sales, memberships, and training sessions.

- 🏷️ **Barcode Reading Support**  
  Scan membership cards and products for faster transactions and check-ins.

- 📊 **Dashboard and Analytics**  
  View summaries of sales, memberships, and upcoming schedules.

- 🛡️ **Secure Login System**  
  Role-based access (admin and staff).

## 🛠️ Tech Stack

- **Language:** Java
- **UI Framework:** Java Swing
- **Database:** MySQL
- **Reporting:** JasperReports
- **Barcode Handling:** ZXing Library (for barcode scanning and generation)

## 🚀 Getting Started

### Prerequisites

- Java JDK 8 or above
- MySQL Server
- JasperReports Library
- ZXing Library (for barcode functionality)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/RogueChocoholic/flexGym-App.git
   
2. Set up the MySQL database:
   - Import the database dump file provided in `/database/flexgym.sql`.

Configure database connection settings:
   - Update database URL, username, and password in the configuration files.

Run the application:
   - Open the project in NetBeans or your preferred Java IDE.
   - Build and run the project.
